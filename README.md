A program that sums up Thursday 26 November 2026's world news in one
1024×1024 image. Lead story: the escalating war in Yemen; also Ukraine's
strike on five Russian jets, the 5.6 quake in Nepal, and Pakistan's first
astronaut.

## Run

```sh
node main.ts out/entry.png
```

Node 22, standard library only — no network, no randomness, no clock. Two
runs write identical bytes.
